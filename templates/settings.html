    How to set up (about 5 minutes)
    1. Create a free account at backblaze.com.
    2. Go to Buckets → Create a Bucket. Pick a unique name, set it to Private, and create it.
    3. On the new bucket, click Lifecycle Settings and choose Keep prior versions for this number of days: 7. This keeps deleted backup pieces for a week as a safety net, then removes them so you don't pay for them forever.
    4. Go to Application Keys → Add a New Application Key. Allow access to this bucket only with Read and Write. Copy the keyID and applicationKey (Backblaze shows the second one only once).
    5. Paste the two keys below and click Save & Connect. The app finds your bucket by itself, then shows your recovery key.
